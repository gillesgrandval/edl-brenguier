# Installer EDL Brenguier sur la tablette

L'application s'installe depuis Chrome, comme une application ordinaire, sans passer par le Play Store. Une fois installée, elle fonctionne **sans Internet**.

## 1. Installer l'application (une seule fois)

1. Sur la tablette, ouvrez **Chrome**.
2. Allez à l'adresse : **https://gillesgrandval.github.io/edl-brenguier/**
3. Attendez une dizaine de secondes : l'application se prépare pour fonctionner hors ligne (environ 17 Mo, une seule fois).
4. Touchez le menu **⋮** (en haut à droite de Chrome), puis **« Installer l'application »** (ou « Ajouter à l'écran d'accueil »).
5. Confirmez. L'icône **GB bleue** apparaît sur l'écran d'accueil de la tablette.

À partir de là, ouvrez toujours l'application avec cette icône, et non plus depuis Chrome.

## 2. Vérifier que tout est prêt

En bas de l'écran d'accueil de l'application, trois indications :

- **« Fonctionne hors ligne »** : l'application est entièrement sur la tablette.
- **« Données protégées »** : Android ne supprimera pas les données pour faire de la place. Cette protection est demandée à la création du premier état des lieux ; acceptez-la si Android pose la question.
- L'espace utilisé et l'espace disponible.

## 3. Autorisations à accepter

Au premier usage, Android demande :

- **l'appareil photo** (photos des pièces et des compteurs) : **Autoriser** ;
- **le micro** (dictée) : **Autoriser**.

## 4. Mettre à jour l'application

Quand une nouvelle version est publiée, un bandeau apparaît : **« Une nouvelle version de l'application est disponible »**. Touchez **« Mettre à jour »**.

- Les états des lieux, photos et signatures **sont conservés**.
- Si vous êtes en pleine saisie, touchez « Plus tard » et mettez à jour à la fin de la visite.
- Si le bandeau ne vient pas, fermez complètement l'application (balayez-la dans la liste des applications ouvertes), puis rouvrez-la.

## 5. Protéger ses données

Les données sont **uniquement sur la tablette**. Trois règles :

1. **Faire une sauvegarde régulière** : Paramètres (⚙) → « Créer une sauvegarde complète » → « Partager » → Google Drive. Idéalement après chaque journée d'états des lieux.
2. **Ne jamais** utiliser « Effacer les données » de Chrome pour ce site, ni désinstaller l'application sans sauvegarde récente : cela efface tout.
3. **Verrouiller la tablette** par un code ou une empreinte (réglages Android) : les données personnelles des locataires y sont stockées.

## 6. Changer de tablette ou en ajouter une

1. Sur l'ancienne tablette : Paramètres → **Créer une sauvegarde complète** → Partager → Google Drive.
2. Sur la nouvelle : installer l'application (étape 1), puis Paramètres → **Restaurer une sauvegarde** → choisir le fichier .zip depuis Google Drive.

Chaque tablette a sa propre base : il n'y a pas de synchronisation automatique entre appareils.

## 7. Sur un ordinateur ou un téléphone

L'application fonctionne aussi dans Chrome sur ordinateur ou téléphone (même adresse). Elle est pensée d'abord pour la tablette.
